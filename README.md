# TODO-планировщик на Go

Это веб-приложение, которое позволяет управлять задачами с поддержкой повторений.

## ✅ Выполненные задания со звёздочкой

- **Шаг 1**: Поддержка порта через `TODO_PORT`
- **Шаг 2**: Поддержка пути к БД через `TODO_DBFILE`
- **Шаг 3**: Полная поддержка правил повторения (`d`, `y`, `w`, `m`)
- **Шаг 5**: Поиск задач по тексту и дате
- **Шаг 8**: Аутентификация через JWT

## 🚀 Запуск локально

1. Установите Go 1.24+.
2. Склонируйте репозиторий.
3. Запустите:
   ```bash
   go run main.go
4. Перейдите по адресу:
   http://localhost:7540

**Примечание**
В структуре проекта присутствует .env:
   TODO_PORT=7540
   TODO_DBFILE=scheduler.db
   TODO_PASSWORD=12345

## 🧪 Запуск тестов

Если будете прогонять тесты.
Для запуска всех тестов нужно:
```bash
1. Запустить сервер:
    go run main.go
2. Запустить тесты:
    go test ./tests

**Примечание**
если включена аутентификация (TODO_PASSWORD),
перед запуском тестов необходимо получить валидный JWT-токен
и указать его в tests/settings.go → переменная Token (var Token = "ваш_токен_здесь").

**Порядок действий**:
```bash
1. Запустить сервер (указывать пароль в команде не нужно, т.к. есть файл .env):
    go run main.go
2. Получить JWT токен:
    curl -X POST http://localhost:7540/api/signin \
     -H "Content-Type: application/json" \
     -d '{"password": "12345"}'
3. Указать JWT токен в `tests/settings.go` → переменная `Token`:
    var Token = "ваш_токен_здесь"
4. Запустить тесты:
    go test -count=1 ./tests

🐳 Запуск через Docker

```bash
1. Соберите образ:
    docker build -t todo-app .
2. Запустите контейнер:
    docker run -p 7540:7540 \
           -e TODO_PASSWORD=12345 \
           -v $(pwd)/data:/data \
           todo-app
3. Перейдите по адресу:
    http://localhost:7540
